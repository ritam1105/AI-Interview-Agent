# AI Interview Agent

## Overview

AI Interview Agent is a full-stack application that connects a user-facing client with a backend server to provide an intelligent interview experience. The project is organized into two main directories:

- `client`: Frontend application for users and interview flow.
- `server`: Backend API and business logic for processing interview data.

## Features

- Interactive interview session management
- AI-based question generation and response evaluation
- Clean separation between frontend and backend
- Ready for deployment and GitHub hosting

## Project Structure

```text
/ (repository root)
├── client/      # Frontend application
├── server/      # Backend service
└── README.md    # Project documentation
```

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/ai-interview-agent.git
   cd ai-interview-agent
   ```

2. Install dependencies for each part:

   ```bash
   cd client
   npm install
   cd ../server
   npm install
   ```

## Running the Project

### Client

From the `client` directory:

```bash
npm start
```

### Server

From the `server` directory:

```bash
npm start
```

## Deployment

- Host the `client` on a static site service or as part of a full-stack deployment.
- Run the `server` on a Node.js-compatible host or container.
